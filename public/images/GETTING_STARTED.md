## 🚀 How to Add Images:

1. **Download/Create your images**
2. **Rename them** according to the structure above
3. **Copy them** to the appropriate folders in `/public/images/`
4. **Refresh your browser** - they should appear automatically!

## ✨ Pro Tips:

- **Optimize images** for web (use tools like TinyPNG)
- **Use consistent aspect ratios** for better visual flow
- **Add WebP versions** for better performance
- **Include alt text** for accessibility
